# 🏆 AI ARENA 2026

## AI-Assisted Machine Learning Hackathon

# 🧠 What Makes AI ARENA Different?

This is not simply a "train a model and get accuracy" competition.

The challenge includes:

* Unseen test samples
* Difficult edge cases
* Distribution shifts
* Noise and variations
* Class imbalance
* UNKNOWN / uncertain cases
* Private evaluation data
* Working prototype requirements
* Live technical challenges

Your model needs to **generalize**, not just memorize the training data.



# 🤖 AI Usage Policy

AI tools are **allowed**.

You may use:

* ChatGPT
* Claude
* Gemini
* GitHub Copilot
* Other AI coding assistants

However, your team must understand the submitted solution.

During final judging, teams may be asked to:

* Explain their model
* Explain preprocessing
* Justify model selection
* Explain validation methodology
* Analyze model errors
* Modify the solution live
* Answer technical questions

**AI assistance is allowed. Blind dependence on AI is not a substitute for technical understanding.**



# 📊 Evaluation

Final evaluation is based on **100 marks**.

| Evaluation Heading            |   Marks |
| ----------------------------- | ------: |
| Hidden-Test Macro F1          |  **30** |
| Robustness / Unknown Handling |  **15** |
| ML Methodology                |  **15** |
| Working Prototype             |  **15** |
| Innovation                    |  **10** |
| Real-World Usefulness         |   **5** |
| Presentation & Q&A            |  **10** |
| **TOTAL**                     | **100** |

### Hidden Test

The final evaluation includes **private test data and labels** that will not be provided to participants.

Your submitted predictions will be evaluated against the private labels.



# 📤 Submission Requirements

Each team must submit:

### 1. `submission.csv`

Follow the exact format provided in the track folder.

Example:

```csv
sample_id,predicted_class,confidence
CG_0001,Class_A,0.92
CG_0002,Class_B,0.81
CG_0003,Class_A,0.74
```

### 2. Source Code

Submit the complete code used to develop and generate your final predictions.

### 3. Technical Report

Your report should include:

* Problem understanding
* Dataset analysis
* Preprocessing
* Model selection
* Training methodology
* Validation results
* Error analysis
* Final approach
* Limitations
* Future improvements

### 4. Working Prototype

Your team must demonstrate a working version of your solution during final judging.



# ⚠️ Important Rules

## 💡 Tip

Don't immediately build the most complicated model.

A well-understood, properly validated model with good error analysis can outperform a complex model that has not been tested properly.
